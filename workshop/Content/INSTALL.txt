Quest Tracker - Installation
============================

Shows the items you still need for faction missions and seed research,
on the game screen beside the built-in mission tips.


1. Requirement: BepInEx
-----------------------
This mod needs BepInEx.

The easiest way to get it is to subscribe to "DTMAPI" on the Workshop,
which installs BepInEx along with it.

If you already run other BepInEx mods, skip this step.


2. Copy the DLL
---------------
Copy DolocTownQuestTracker.dll from this folder into:

  ...\steamapps\common\Doloc Town\BepInEx\plugins\

Drop it straight into the plugins folder -- no subfolder needed.


3. Check that it works
----------------------
Start the game, load a save, then open a faction NPC or the seed
research screen.

Each mission and seed now has a small switch. Turn one on and the
items it needs appear on the right side of the game screen.

You can track up to 5 at a time. Completed ones disappear on their own.


Uninstalling
------------
Delete BepInEx\plugins\DolocTownQuestTracker.dll

To remove your settings as well, also delete
BepInEx\config\randommagic.doloctownquesttracker.cfg


Settings (optional)
-------------------
BepInEx\config\randommagic.doloctownquesttracker.cfg

  OffsetY                 How far down the overlay sits. Raise or lower
                          it if it overlaps the game's own mission tips.
  Marquee                 Scroll long item lists. Set to false to wrap
                          them over several lines instead.
  CountNearbyContainers   Also count chests in the room you are standing
                          in. Off by default.

Your backpack, and any box carried inside it, are always counted.

The defaults are fine -- you do not need to edit anything.
